# Camera Urdu Translator (Android Studio project)

یہ اینڈرائیڈ ایپ تصویر میں موجود انگریزی متن کو ML Kit OCR کے ذریعے پڑھتی ہے اور Google ML Kit کے English-to-Urdu ماڈل سے اردو ترجمہ کرتی ہے۔

## استعمال
1. ZIP کو Extract کریں۔
2. Android Studio میں `CameraUrduTranslator` فولڈر کھولیں۔
3. Gradle Sync مکمل ہونے دیں۔
4. موبائل کو USB سے جوڑ کر Run دبائیں، یا Build > Build APK(s) منتخب کریں۔
5. پہلی مرتبہ اردو ترجمہ ماڈل ڈاؤن لوڈ کرنے کے لیے انٹرنیٹ درکار ہوگا۔ ماڈل ڈاؤن لوڈ ہونے کے بعد ترجمہ آف لائن بھی چل سکتا ہے۔

## اہم بات
- کیمرہ بٹن فی الحال Android کی camera app کھول کر تصویر کا preview لیتا ہے؛ مکمل ریزولوشن کیمرہ کیپچر اگلے ورژن میں شامل کیا جا سکتا ہے۔
- OCR انگریزی/لاطینی حروف کے لیے ہے؛ صاف، روشن اور سیدھی تصویر سے بہتر نتیجہ ملتا ہے۔
- یہ Android Studio کا سورس پروجیکٹ ہے، پہلے سے تیار APK نہیں۔
